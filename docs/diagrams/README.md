# Diagramas

Um diagrama por arquivo, em `.drawio.svg`: o GitHub e o site mostram o SVG, e a extensão
`hediet.vscode-drawio` abre o mesmo arquivo para edição no VS Code. O que ainda não existe aparece
tracejado, com o marco.
