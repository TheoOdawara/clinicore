# Glossário

Os termos de domínio que os requisitos usam, uma linha cada.

| Termo | Significado |
| --- | --- |
| Anamnese | Histórico de saúde do paciente, colhido antes do tratamento |
| Assinatura avançada | Assinatura eletrônica que identifica o signatário sem certificado ICP-Brasil (Lei 14.063/2020) |
| Assinatura qualificada | Assinatura eletrônica feita com certificado ICP-Brasil (Lei 14.063/2020) |
| Cliente | Quem contrata o produto: clínica única, rede ou dentista autônomo; é o tenant |
| Clínica | Unidade de atendimento de um cliente |
| Dentista autônomo | Dentista que é cliente por conta própria, sem clínica por trás |
| Encaixe | Consulta marcada num horário já ocupado |
| Evolução | Registro do que foi feito num atendimento |
| Glosa | Recusa de pagamento, total ou parcial, de uma guia pela operadora |
| Go-live | Dia em que a clínica piloto passa a operar no sistema e deixa o Simples Dental |
| Harmonização orofacial | Procedimentos estéticos da face feitos pelo dentista, como toxina botulínica, preenchedor e bioestimulador |
| ICP-Brasil | Infraestrutura de Chaves Públicas Brasileira, que emite os certificados da assinatura qualificada |
| LCP | Largest Contentful Paint: tempo até o maior conteúdo da tela aparecer |
| Lista de espera | Pacientes que aguardam um horário mais cedo que o marcado |
| NFS-e | Nota Fiscal de Serviço eletrônica |
| NGS2 | Nível de garantia de segurança 2 do prontuário eletrônico, que exige certificado ICP-Brasil |
| Odontograma | Representação dos dentes do paciente com a situação de cada um |
| Operadora | Empresa de convênio odontológico |
| Orçamento | Proposta de valor de um plano de tratamento, apresentada ao paciente |
| p95 | Percentil 95: valor abaixo do qual ficam 95% das medições |
| Passkey | Credencial que entra com a biometria ou o bloqueio do aparelho, sem senha |
| Plano de tratamento | Conjunto de procedimentos propostos ao paciente |
| Prontuário | Registro clínico do paciente: anamnese, odontograma, plano, evoluções e documentos |
| PSC | Prestador de Serviço de Confiança: guarda o certificado em nuvem do dentista |
| PWA | Aplicação web instalável no dispositivo |
| Rede | Cliente com várias clínicas, cada uma com gestor próprio |
| Repasse | Parte do valor recebido que cabe ao dentista que realizou o procedimento |
| Responsável legal | Quem assina pelo paciente menor de idade |
| Tenant | O cliente, visto como fronteira de isolamento de dados |
| TISS | Troca de Informações na Saúde Suplementar: padrão de arquivo para faturar convênio |
